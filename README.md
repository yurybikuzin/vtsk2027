# vtsk2027

Исследовательский проект для Банка России по теме ребалансировки депозитов частного сектора при изменении доходности, конкуренции рынка акций и альтернативных инструментов инвестирования. Научный руководитель Сергей Александрович Переход.

В репозитории лежит панель квартальных данных 2018Q1–2026Q2 по 30 столбцам и код, который её собирает, обогащает и оценивает регрессии по гипотезам H1–H16. Все расчёты на Rust, без Python и R.

## Структура

`data/given` это исходные файлы и постановка. `data/downloaded/CBR_Deposits_Sources_Registry_2026-11-07` это скачанные файлы ЦБ и Росстата. `data/constructed` это результат сборки, включая `cbr_panel.xlsx` и обогащённую панель. `data/tmp` это промежуточные просмотры.

`tools/rs` это cargo workspace с крейтами `cbr-panel`, `cbr-fetch`, `rosstat-fetch`, `excel-sampler`, `excel-split` и `collect`. `cbr-panel` единая точка входа с подкомандами `panel`, `extract-config`, `quarterly`, `merge`, `check`, `enrich`, `export-csv`, `regress` и четырьмя `fetch-*`. `collect` обслуживает `tree` и `bundle`.

## Сборка

`make all` качает файлы ЦБ и Росстата и собирает панель. `make force` делает то же с перекачкой всего. `make build` собирает все крейты без запуска. `make tree` и `make bundle` пишут `tree.tools.txt`, `tree.data.txt` и `bundle.txt`. `make clean` убирает сгенерированные артефакты.

Панель собирается по шагам: `panel` из четырёх файлов ЦБ, потом `extract-config` и `fetch-key-rate`, `fetch-zcyc`, `fetch-moex`, `fetch-usd` дают длинные таблицы, `quarterly` сворачивает их в кварталы, `merge` приклеивает к панели с обрезкой по `--min-quarter 2018Q1 --max-quarter 2026Q2`, `enrich` добавляет производные столбцы, `check` печатает покрытие. Все шаги описаны в Makefile.

## Ограничения

Реальные располагаемые денежные доходы населения `G` и цены на жильё пока недоступны, потому что страницы Росстата отдают 404. Пока рядов нет, `G` в панели отсутствует, и гипотезы с ним как контроль проверить нельзя. Это известное ограничение, не блокер для базовых гипотез по депозитам и акциям.

`infl_exp_y5` начинается с 2023Q1, потому что в исходнике пятилетние ожидания есть только с этого момента. 2020Q2 и 2020Q3 по инфляционным ожиданиям пустые, потому что опросы не проводились. `d_usd` с 2018Q2, потому что для 2018Q1 нет предыдущего квартала.

## Документация

`tools/rs/cbr-panel/README.md` содержит методологию сборки панели, источники, правила приведения к кварталу и зафиксированную интерпретацию результатов по H1–H5. `bundle.txt` собирает исходники, конфиги и ignore-файлы в один файл для чтения и передачи.
